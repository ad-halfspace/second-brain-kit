# Brain Index

Master map of `agent_brain/`. Keep this updated when pages are created or removed.

## Organization principle

The brain is **opinion-first, not catalog-first**. Pages exist because they serve a decision, a draft, or a take. The exception is the **hub layer** at `agent_brain/references/`: thin navigational indexes for large topics. See [[understanding/standards/topic-hubs|topic-hubs standard]].

## Entity-first structure

Every project lives in **one folder at the vault root** (see [[understanding/standards/entity-first-structure|entity-first-structure standard]]):

- **`clients/<name>/`**: external paid engagements
- **`projects/<name>/`**: internal initiatives
- **`personal/<name>/`**: personal-life projects

**Tasks stay in `agent_brain/tasks/`** and **people in `agent_brain/people/`** (central, linked from each hub). **Live code stays in `workspace/`**.
