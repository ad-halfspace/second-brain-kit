# Halfspace Project Excellence — Kickstart Playbook

Source: [Project Excellence Notion page](https://www.notion.so/halfspaceai/Project-Excellence-b91032fe0b484acf8c9dfa5ea6e59205)

## The 5 Project Hats (all must be assigned)

| Hat | Owner focus |
|-----|------------|
| 🧭 Project Lead | Project & team mgmt, planning, direction, risk classification |
| 🔧 Tech Lead | Code quality, DevOps, architecture |
| 🧪 Solution Lead | Solution value, methodology |
| 💼 Commercial Lead | Expansion opportunities, client budgets, contract |
| 🧑‍💼 Client Lead | Compliance, strategic client relationship & growth |

One person can hold multiple hats. **All 5 must be assigned before kickoff.**

---

## Phase 1: Start — Setting up for success

### Checklist (Project Lead)

**Preparation (before any meeting)**
- [ ] Read up on and understand the client's business
- [ ] Map client stakeholders (roles, influence, interest)
- [ ] Understand context and problem — read the scope/SoW
- [ ] Ensure all 5 hats are appointed (align with Partner)
- [ ] Align with Partner on scope, contracts, and risks (PII, NDA, SoW)
- [ ] Complete compliance check — legal, ethical, data issues (CDP tool)
- [ ] Classify AI system risk level per EU AI Act (if AI in EU)
  - Resource: [EU AI Act compliance checker](https://artificialintelligenceact.eu/assessment/eu-ai-act-compliance-checker/)

**Setup (Week 1)**
- [ ] Create Notion project page (duplicate template, ask Kasper Nagel to set up client space if new client)
  - Template: [Project Template](https://www.notion.so/31a1049b7e6680b4841be47f4b7712f5)
- [ ] Set up project in Accenture CDP tool
- [ ] Set up team in RORO
- [ ] Order client computers / logins if needed
- [ ] Ensure all relevant system accesses
- [ ] Request Meeting Recordings access (Teams recording, 2–3 people per team — ask KNN)
- [ ] Set up DevOps board

**Meetings to book (Week 1–2)**
- [ ] Book internal Team Kickoff (60 min) — use agenda template from PE PPT
- [ ] Book Client Kickoff — align on problem, scope, responsibilities, expectations
- [ ] Book all recurring internal meetings (standups, Monday planning, team temperature)

---

## Phase 2: During — Driving quality and collaboration

### Recurring meeting cadences

| Meeting | Frequency | Duration | Notes |
|---------|-----------|----------|-------|
| Daily Standup | Daily | 15 min | Quick sync, stay focused, unblock |
| Weekly Planning | Weekly (Mon) | 60 min | Align goals, update backlog, assign tasks |
| Problem Solving Session | Weekly | 60 min | Team + invited experts challenge WIP |
| Client Standup | Weekly or bi-weekly | 30 min | Track progress, resolve blockers |
| Client Review | Monthly or milestone-based | 60–90 min | Present deliverables, get feedback |
| Team Temperature (PIE) | Weekly add-on | 10–15 min | Physical / Intellectual / Emotional check-in |
| 1:1 People Growth (mid-project) | Mid-project | 30 min | Growth goals, feedback, support |
| Delivery Excellence Review | As needed | 60 min | Internal code/solution review by domain experts |
| SteerCo | Monthly or milestone-based | 60 min | Executive/senior stakeholder status |

---

## Phase 3: End — Wrapping up & learning

- [ ] Retrospective 1 — Pre-handover Risk Review (delivery risks, handover readiness)
- [ ] Retrospective 2 — Project Reflection (what went well, what to improve)
- [ ] Handover — all assets, documentation, tech transitions, AI Act risk documentation
- [ ] Reference Case — capture project story for sales/marketing/pitches
- [ ] 1:1 People Growth (project end) — reflect on growth journey

## House style & preferences (apply on every kickoff run)

Starter defaults from a real strategy-engagement kickoff. Edit these to your own preferences; apply by default and confirm only where the engagement clearly differs.

**Hard constraints (default unless told otherwise)**
- **Notion is read-only** — do NOT create/duplicate pages. Flag the step + the Kasper Nagel new-client-space dependency for the user to do manually.
- **Do NOT send calendar invites or create events.** Output suggestions + draft invite text; the user sends.

**Hats**
- One person can hold several; **"no [hat]" is valid** when the engagement doesn't need it (e.g. no Tech Lead on a strategy-only engagement → then skip DevOps board / system-access setup). Don't force all five onto distinct people.
- Carry a proposed allocation, flag the uncertain ones to align with the Partner — don't block the run.

**Meeting cadence (strategy engagement)**
- Bias toward **fewer, higher-signal meetings**.
- **Team Temperature (PIE): Friday, 25 min, standalone** — not bundled into Monday planning.
- A **dedicated weekly client/sponsor status (30–60 min)** as a standing session — not just a bi-weekly standup.
- A **pre-milestone / pre-ELT alignment session**, pulling in the exec/CEO where relevant.
- An **embedded client resource (~50%)** joins the internal rhythm on a **Mon/Wed/Fri** pattern, not every daily standup.
- **Start-of-project development-goals 1:1** with each new senior hire; **recurring (bi-weekly) steering 1:1** with the oversight lead; mid-project people-growth 1:1s as the later check-in.

**Invites — logistics**
- **One task per invite** (not a single umbrella) for tracking; group them under a tracker task.
- **Keep the INTERNAL series separate from the EXTERNAL/client series**, and prefix each task name `Internal invite —` / `External invite —`.
- **Internal invites go out early — no later than the Monday after kickoff** — to hold recurring slots (especially before a summer break). External can follow on their own timing.
- Put a **suggested invite text in each task drawer**, as a **plain-text code box with `•` bullets** so Outlook paste stays clean (markdown `-`/`**`/`>` come through literally — avoid them).

**Invite voice / language**
- Source the voice from the PE Framework Template + the user's own invite examples (add a link here). Reuse the PIE 1–5 wording.
- Sign-off: <YOUR_SIGN_OFF> for internal, <YOUR_CLIENT_SIGN_OFF> for client-facing.
- **Language:** English whenever an English-speaker **or the client** is involved; Danish only for fully-internal Danish-speaker meetings. 1:1s follow the person.

**Brain hygiene after a kickoff**
- Keep a **"Deliverables (current)"** section in the project hub, flagged with its update trigger (e.g. "update after the next client meeting") + a linked update task.
- Maintain a running **"align with [oversight lead]"** list in `notes/`.
- Update the hub: PE Start-Phase section, hats, blockers, and task links.
